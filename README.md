# Bingo Maker

Picture bingo for speech therapy. Live at **https://ppspeech.github.io/bingo-maker/** (once GitHub Pages is switched on).

- Type a word list (one per line), or start from ~100 ready-made sets: sounds by position, blends and minimal pairs, all in Australian English.
- Pictures are added automatically for about 1,500 kid words. Put your own emoji in front to change one (`🕷️ spider`).
- 3×3, 4×4 or 5×5 grids, optional FREE square, 1–8 cards, each shuffled differently.
- **Play on screen:** two boards (clinician and child), a big Call button, auto-mark or tap-to-mark, hide-the-word mode for listening, and a BINGO! celebration.
- **Download PDF to print:** one card per A4 page, plus cut-out call cards.

Everything runs in the browser. Word lists and settings are remembered on the device only.

Word lists and pictures come from Sound Check (ppspeech/sound-check).
